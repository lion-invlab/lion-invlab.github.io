投資判讀｜先看變化，再看水位

VIX｜市場避險需求

VIX 上升代表選擇權市場反映的未來波動預期升高，不代表市場必然下跌。先觀察升速與是否持續，再搭配股市走勢判讀。

NFCI｜金融環境是否收緊

高於 0 代表金融條件較長期平均緊縮；低於 0 代表較寬鬆。由負轉正或持續上行，比單週的小幅波動更值得注意。

STLFSI4｜金融市場壓力

0 代表正常水準；高於 0 表示高於平均的金融壓力，低於 0 則低於平均。持續走高比單週短暫跳升更值得警戒。

交叉確認｜避免單一指標誤判

若 VIX 急升，但 NFCI 與 STLFSI4 仍低於 0，可能偏向股市短期避險需求；若三者同步走高，則代表壓力可能擴散至整體金融環境。NFCI Credit 僅作為 NFCI 的信用面補充。
