## 強制規則

1. 每次製作先讀根目錄 `TAC_WORK_RULES.md` 與本目錄 `mother-template-manifest.json`。
2. 只允許依星期情境讀取上述對應檔案；不得從首頁、歷史早報、preview、測試分支或其他舊檔案挑選替代版本。
3. 必須核對路徑、SHA 與星期專用區塊；任何驗證失敗立即停止，不得自動 fallback。
4. 只有使用者明確核准母版變更後，才能修改母版並同步更新 manifest SHA、工作規則與本 README。
5. `TAC_WORK_RULES.md` 根目錄檔是正式規則主檔；本目錄的同名檔是同步副本，必須保持一致。
6. 每日審核版另存獨立日期檔。正式首頁 `index.html` 不是母版，未經明確授權不得修改。

歷史版本與測試分支可為追溯用途保留，但不具有每日製作母版資格。
